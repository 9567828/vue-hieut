# vue-hieut
---
### 기획 의도
학원에서 인연이 된 스타트업 대표로부터 회사 소개 사이트 제작 의뢰를 받아 진행한 프로젝트입니다.<br/>
순수 HTML/CSS/JS로 제작 후 Vue.js로 리빌드했습니다.<br/>
vue.js 리빌드 주소: https://hieut-vue.netlify.app/.<br/>

## 기술 스택
- Vue.js, Vue Router
- SCSS (mixin 활용)
- Figma (디자이너 협업)

## 주요 구현
- Vue Router로 페이지 라우팅 구현
- 컴포넌트화로 재사용성 향상
- SCSS mixin으로 반복 스타일 관리
